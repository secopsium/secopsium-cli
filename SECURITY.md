# Security Policy

## Supported Releases

Security fixes are applied to the latest supported release on GitHub.

## Reporting a Vulnerability

Please do not open a public issue for suspected vulnerabilities.

Use GitHub's private vulnerability reporting for this repository if it is enabled.
If private reporting is not available, contact the maintainers through the private contact channel listed on https://secopsium.com.

When reporting a vulnerability, include:
- affected version or commit
- operating system and architecture
- reproduction steps
- impact assessment, if known

## Scope Notes

This CLI is designed to stay transparent and local-first. Security reports are especially helpful for:
- managed tool installation and update flow
- subprocess execution and path handling
- repository cloning and filesystem behavior
- redaction and output safety
